## 安装 NexusPilot

当前公开下载渠道和平台状态以[官网下载区](https://nexuspilot.dev/#download)为准。下载完成后，运行安装程序并按系统提示完成安装。

首次启动时，NexusPilot 会创建保存本地应用配置所需的目录和数据。安装与升级不会要求你把数据库连接信息交给网页端。

## 开始前的准备

在创建第一个连接前，请准备好目标数据源提供的连接信息：

- 地址和端口，或本地数据库文件路径；
- 登录所需的用户名与密码；
- 数据库、schema 或其他默认上下文（如适用）；
- TLS、SSH 或服务端要求的额外连接参数。

不同数据源的当前可用状态请查看[官网数据库支持矩阵](https://nexuspilot.dev/#databases)。

## 安装后确认

启动应用后，确认工作台能够正常打开。接下来可以继续阅读[5 分钟快速开始](/getting-started/quick-start/)，完成一次连接、对象浏览和查询。

如果应用无法启动，或 Windows 阻止安装，请先查看[故障排查](/help/troubleshooting/)。

## 更新

NexusPilot 会在后台检查可用更新，不阻塞你打开工作台。发现新版本后，可以先查看更新说明，再决定是否下载和安装。

更新前建议：

- 完成或保存正在编辑的内容；
- 关闭不再需要的数据库连接和标签页；
- 在更新说明中确认是否包含你关心的修复或行为变化。

版本变更和发布说明集中在[发布日志](/releases/)。
