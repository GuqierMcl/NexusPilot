---
title: 故障排查
description: 排查安装、连接、对象加载、查询和 AI Runtime 的常见问题。
---

遇到问题时，先记录错误信息、发生时间、所用数据源类型和复现步骤。不要在截图、日志或反馈中包含密码、访问令牌、完整连接字符串或敏感业务数据。

## 无法安装或启动应用

1. 确认安装包来自[官网](https://nexuspilot.dev/#download)。
2. 关闭可能仍在运行的旧版本，再重新启动应用。
3. 检查系统安全软件是否阻止安装程序或应用启动。
4. 尝试重新下载安装包，并查看[发布日志](/releases/)中的已知变更。

若问题仍然存在，请保留系统提示和最小复现步骤后再反馈。

### macOS 提示无法验证开发者

当前公开 macOS 包使用 ad-hoc 代码签名。确认 DMG 来自官网下载后，先尝试打开一次 NexusPilot，再进入“系统设置 → 隐私与安全”，在安全区域点击“仍要打开”并完成系统确认。系统会为这个应用保存一次例外。

如果安全区域没有出现“仍要打开”，请重新尝试启动应用后再检查。若提示应用已损坏，请重新下载当前版本；持续出现时请保留 macOS 版本、安装包架构和完整提示后反馈，不要关闭整个系统的安全检查。

## 无法打开数据库连接

按以下顺序检查：

1. 主机、端口、用户名、密码和数据库 / schema 上下文是否正确；
2. 目标服务是否正在运行，且当前网络能够访问它；
3. 数据库账号是否有登录和读取元数据所需的权限；
4. TLS、SSH、证书或代理配置是否与服务端要求一致；
5. 是否在正确的网络环境、VPN 或堡垒机路径中连接。

不要仅通过重试掩盖认证或网络问题。先阅读错误信息，再修正配置。

## 对象树为空或对象无法展开

确认连接状态为已连接后，再展开父节点。若仍为空：

- 检查当前账号是否拥有查看库、schema 或对象目录的权限；
- 确认目标数据库中确实存在预期对象；
- 重新打开连接，避免使用已经失效的会话；
- 检查是否把错误的数据库、schema 或逻辑库设为当前上下文。

## 查询没有返回预期结果

检查 SQL 使用的连接和上下文是否正确，并先以只读、小范围查询验证。例如增加明确的筛选条件和 `LIMIT`，再逐步扩大范围。

如果查询失败，请记录数据库返回的错误文本；如果结果为空，请验证表名、schema、条件和当前账号权限。

## AI 助手不可用

数据库工作台的基础连接和浏览能力不应依赖 AI。若 AI 助手无法使用：

1. 检查本地网络是否能够访问已配置的模型提供商；
2. 检查应用设置中的模型或提供商配置；
3. 重新打开应用后再试；
4. 若问题持续，记录 AI Runtime 的可见错误信息，但不要附上密钥或完整对话中的敏感数据。

如果“设置 → AI 能力 → 运行时”显示版本不匹配，请通过页面中的按钮前往官网，重新下载并安装最新版 NexusPilot。安装后，主程序和配套的 AI Runtime 将更新为同一版本。

## 上下文已整理或模型提示上下文超限

长对话中出现“上下文已整理”标记是正常现象：Runtime 会为当前模型请求构造有界上下文，而原始对话、工具记录、审批和附件引用仍保留在本机。编辑已完成的用户消息后，默认对话会显示新的当前分支；这不会删除旧分支事实，也不会撤销已经发生的数据库或外部操作。

上下文主百分比表示 Runtime 对下一轮调用占用目标模型窗口的估算；一轮完成后会包含最新 Assistant 内容。Provider 最近实测输入和输出预留是分开的辅助信息，不参与主百分比，因此同一模型、分支和策略下追加对话时不会因请求阶段切换而反向跳动。成功压缩、编辑或切换分支、切换模型或策略变化时，主值可以重新计算并下降。若显示未知，说明当前没有可用的可信窗口事实；选择一个声明有效上下文长度的模型、重新发送一次消息后再检查即可。

如果出现“上下文压缩失败”，说明达到阈值后的摘要 gate 没有产生可用 checkpoint；Runtime 会停止本轮，不会静默回退到完整 raw history。对于 reasoning 模型，只有明确因 reasoning 独占输出预算而以 length 结束时才会扩大合法输出预算并缩小摘要输入重试一次。若 Provider 仍返回“context length exceeded”等错误，请保留错误正文和最小复现步骤。Runtime 只会在当前请求尚未有输出、工具、审批或副作用时，对同一模型安全恢复一次；不会自动换模型、删除原始历史或重放已执行操作。Provider/AI SDK 错误正文会保留原有换行和文字（仅精确隐藏当前 Runtime 持有的完整 secret），因此可直接复制到反馈中，但请先确认其中不含业务敏感信息。

## 提交修改后出现冲突或结果未知

不要立即重复提交。先刷新或重新读取目标对象，确认远端最终状态，再根据实际结果重新编辑或提交。对于生产数据，应遵循团队的变更流程并保留审计信息。
