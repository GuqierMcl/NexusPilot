---
title: 数据库连接
description: 创建、组织、打开和断开连接，并理解连接状态对工作台的影响。
---

连接配置保存在本地工作台中，用于告诉 NexusPilot 如何访问一个数据源。连接是否可用由实际的运行时连接结果决定，而不是仅由保存成功决定。

## 创建连接

在连接浏览器中选择新建连接，然后：

1. 选择数据源类型；
2. 填写该类型要求的地址、端口或文件路径；
3. 填写用户名、密码和默认上下文等可选信息；
4. 根据目标服务要求配置 TLS、SSH 或其他高级连接参数；
5. 保存并打开连接，确认状态正常。

连接表单会随数据源类型变化。请只填写目标数据库或服务端提供的参数，避免将凭据粘贴到查询编辑器、日志或不受信任的对话中。

连接名称属于所有数据源共用的连接信息，并会优先显示在各数据源的连接参数之前。颜色、标签文本和备注集中在参数下方默认折叠、与主表单明确分隔的“外观与备注”区域；即使编辑或克隆的连接已有这些内容，该区域也保持折叠，并在单行标题摘要中直接显示已有备注，较长内容会按可用宽度省略。备注支持最多 50 个字符的多行纯文本，适合记录用途、负责人或环境注意事项。备注只作为你的自定义说明保存，不会改变连接目标、数据库权限或运行行为。

在连接浏览器中将鼠标悬停在连接节点上，或使用键盘将焦点移动到该节点，可以在右侧信息卡中快速确认连接名称、驱动、已配置的颜色与标签、非空备注和核心目标位置。网络数据库会显示地址以及适用的数据库、Schema、Service Name、SID 或已填写的 Redis 数据库索引；SQLite 会显示文件路径和访问模式。未配置的标签、备注和可选目标字段会被省略，以保持信息卡紧凑。信息卡不会显示密码、SSH 凭据等敏感信息；如需查看或修改完整配置，请打开编辑连接窗口。

## 组织连接

使用文件夹将开发、测试、生产或不同项目的连接分开。连接名称应清楚表达环境和用途，例如：

```text
订单服务 · 开发
订单服务 · 测试
订单服务 · 生产（只读）
```

不要仅依靠名称判断安全性。执行操作前，仍应在工作台中确认当前打开的是正确目标。

## 打开与断开

打开连接后，NexusPilot 才会读取该连接支持的对象和能力。展开对象树会按需继续读取下一层元数据。

断开连接会停止需要远端会话的后续操作。已打开标签页可能仍显示最后读取到的内容，但不应把这些缓存内容当作远端的最新状态。

## 连接状态

常见状态包括：

- **未连接**：配置已保存，但尚未建立可用会话；
- **连接中**：正在建立连接或恢复会话；
- **已连接**：可以读取当前连接已声明支持的能力；
- **已降级 / 重连中**：连接暂时不稳定，等待恢复或重新打开；
- **失败**：当前无法建立或维持连接，需要检查错误信息和目标服务。

连接失败时，请先查看[故障排查](/help/troubleshooting/)。

## 使用前检查

在执行查询、编辑数据或确认变更前，请检查：

- 当前连接的名称和环境是否正确；
- 当前标签页是否绑定到正确的数据库或 schema 上下文；
- 你是否拥有完成该操作所需的数据库权限；
- 目标是否为生产环境，以及是否已准备好备份、审核或变更流程。

当前可创建的连接类型以[官网数据库支持矩阵](https://nexuspilot.dev/#databases)为准。
