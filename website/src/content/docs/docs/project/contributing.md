欢迎参与 NexusPilot 的公开协作。源代码、问题反馈和 Pull Request 均通过 [GuqierMcl/NexusPilot](https://github.com/GuqierMcl/NexusPilot) 管理。

开始前请阅读：

- [CONTRIBUTING.md](https://github.com/GuqierMcl/NexusPilot/blob/main/CONTRIBUTING.md)：开发环境、验证命令和 Pull Request 要求。
- [AGENTS.md](https://github.com/GuqierMcl/NexusPilot/blob/main/AGENTS.md)：代码风格、模块边界和 AI 协作规范。
- [SECURITY.md](https://github.com/GuqierMcl/NexusPilot/blob/main/SECURITY.md)：安全漏洞的私密报告流程。

## 贡献方向

- 多数据库驱动扩展。
- 向量、图等 AI 原生数据库适配。
- 桌面工作台体验优化。
- AI Runtime provider/model 适配。
- 文档、示例和使用指南完善。
- 缺陷复现、问题定位和兼容性反馈。

## 协作原则

- 以可复现的问题描述和清晰的使用场景为基础。
- 数据库驱动、AI Runtime 和桌面端能力需要保持契约清晰。
- 用户可见行为变更应同步更新公开文档。
- 贡献内容应符合项目许可协议和代码规范。

## 提交问题与改动

- 可公开讨论的缺陷和功能建议请提交到 [GitHub Issues](https://github.com/GuqierMcl/NexusPilot/issues)。
- 代码改动请通过 Pull Request 提交，并说明影响范围、验证命令和已知限制。
- 用户可见行为、公开契约或架构发生变化时，请同步更新公开文档。
- 不要在 Issue、Pull Request、日志或截图中提交密码、Token、完整连接字符串或敏感业务数据。
