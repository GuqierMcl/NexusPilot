NexusPilot 已采用 Apache License 2.0 开源。正式源代码仓库位于 [GuqierMcl/NexusPilot](https://github.com/GuqierMcl/NexusPilot)。

## 当前状态

- 通过 [GitHub 仓库](https://github.com/GuqierMcl/NexusPilot) 获取源代码和版本历史。
- 通过 [GitHub Issues](https://github.com/GuqierMcl/NexusPilot/issues) 报告可公开讨论的缺陷和功能建议。
- 贡献代码前请阅读仓库中的 [CONTRIBUTING.md](https://github.com/GuqierMcl/NexusPilot/blob/main/CONTRIBUTING.md) 和 [AGENTS.md](https://github.com/GuqierMcl/NexusPilot/blob/main/AGENTS.md)。
- 安全漏洞请按照 [SECURITY.md](https://github.com/GuqierMcl/NexusPilot/blob/main/SECURITY.md) 私下报告，不要创建公开 Issue。

## 公开范围

正式公开仓库包含：

- NexusPilot Desktop 桌面工作台及其 Tauri / Rust 后端。
- 本地 AI Runtime、provider/model 管理和受控工具执行能力。
- 面向用户的官网和公开文档。
- NexusPilot Cloud 的桌面同步客户端，包括端到端加密和设备授权逻辑。

NexusPilot Cloud 服务端、部署与运营基础设施由独立私有仓库维护，不属于 Apache-2.0 公开仓库。公开的桌面同步客户端不会包含服务端密钥、部署配置或运营数据。

## 参与项目

欢迎贡献数据库驱动、工作台体验、AI Runtime、文档、测试和兼容性改进。请从[参与贡献](/docs/project/contributing/)开始，并在提交前确认改动不包含凭据、私有连接字符串或敏感业务数据。
