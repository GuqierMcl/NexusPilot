NexusPilot 是一个 AI Native 数据库工作台，帮助开发者和数据团队在同一桌面环境中管理连接、浏览对象与数据、编写查询，并在需要时获得 AI 辅助。

## 面向谁

NexusPilot 面向经常需要查看数据库结构、编写查询、检查数据、分析问题或在多个数据源之间切换的开发者和技术用户。

## 一个围绕数据工作的工作台

连接浏览器、对象浏览、查询编辑和数据视图围绕同一个工作区协同，减少在多个工具和上下文之间来回切换的成本。

- 统一管理数据库连接配置。
- 按连接逐层浏览数据库对象、结构和数据。
- 在桌面工作台中完成查询编辑、结果查看和数据浏览。

## 面向更多数据形态扩展

NexusPilot 的连接与能力模型面向关系型、键值型、分析型及更多数据形态持续扩展。不同数据源会按实际支持的能力呈现操作，而不是被强行压缩为同一种界面和工作流。

当前可用的数据源与发布状态以[官网数据库支持矩阵](/#databases)为准。该矩阵是唯一的公开状态来源；本文档不重复维护数据库支持列表。

## AI 智能助手

NexusPilot 的 AI 能力由本地 AI Runtime 承载。前端不直接持有 LLM 凭据，也不直接调用模型 API。AI Runtime 负责 provider/model 配置、运行请求和流式结果边界。

- 用自然语言描述查询和分析目标。
- 辅助理解数据结构、生成 SQL 和整理分析思路。
- AI Runtime 在本地管理模型与提供商配置，前端不直接持有 LLM 凭据。
