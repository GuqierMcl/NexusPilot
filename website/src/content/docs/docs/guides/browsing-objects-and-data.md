---
title: 浏览对象与数据
description: 从连接树定位对象，在数据视图中安全地查看、确认和处理数据。
---

NexusPilot 将远端对象按连接逐层展示。先从对象树定位目标，再根据资源类型打开数据视图或其他适配的工作面。

## 展开对象树

展开一个节点时，NexusPilot 会按需加载下一层元数据。这样可以避免在大型数据源中一次读取所有目录，也意味着首次展开某个节点可能需要短暂等待。

不同类型的连接会返回不同层级，例如数据库、schema、表、视图、对象分组、逻辑库、键或键前缀。不要假设所有数据源都有相同的层次或对象名称。

## 打开数据视图

对可浏览的资源执行打开操作后，工作台会在标签页中加载数据。使用数据视图时建议：

1. 先确认对象名称、连接和上下文；
2. 用分页和筛选缩小范围，避免不必要地读取大量数据；
3. 检查列类型和返回值，再决定是否编辑；
4. 对可能影响多条记录或多个键的操作保持谨慎。

数据读取是否可用、返回哪些字段以及能否编辑，都由当前资源与连接的能力共同决定。

## 编辑与变更预览

当资源支持编辑时，修改通常先保留在当前工作台的变更集中，而不是立即写入远端。保存前请检查目标对象、修改范围和生成的变更计划。

如果工作台未提供新增、编辑或删除入口，通常表示该资源当前为只读，或无法安全地表达对应数据库的写入语义。不要将只读界面误解为连接故障。

## 保持结果可信

数据库内容可能在你浏览期间被其他用户或服务修改。尤其在准备保存变更时：

- 刷新或重新读取关键数据；
- 确认定位条件仍然准确；
- 留意工作台给出的冲突、远端状态变化或结果未知提示；
- 对不确定的结果先核对远端事实，再重新提交。

如果对象树为空、数据视图无法打开或结果与预期不一致，请查看[故障排查](/docs/help/troubleshooting/)。
