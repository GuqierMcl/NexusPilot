---
title: 快速开始
description: 创建第一个连接，浏览对象，并在 NexusPilot 中执行一次查询。
---

本指南以一个你有权访问的非生产数据源为例。请不要把不确定的写入、删除或结构变更直接用于生产环境。

## 1. 创建连接

1. 打开工作台左侧的连接浏览器。
2. 选择新建连接，并选取当前可用的数据源类型。
3. 填写地址、端口、凭据和默认上下文等信息。
4. 保存连接后，打开它并确认连接状态变为可用。

如果不确定某个数据源是否已在当前版本中提供，请查看[官网数据库支持矩阵](/#databases)。

## 2. 浏览对象

展开连接节点。NexusPilot 会按数据源返回的层级按需加载对象；你可能会看到数据库、schema、表、视图、资产分组或键空间等不同结构。

继续展开你需要的对象，选择一张表、一个视图或其他可浏览资源。对象类型和可执行操作取决于该连接实际声明的能力。

## 3. 查看数据

在支持数据浏览的资源上打开数据视图。先确认数据、列和分页结果是否符合预期，再进行任何编辑操作。

有些资源只读是正常行为：NexusPilot 不会把数据库无法安全表达的语义伪装成可编辑表格。

## 4. 执行查询

打开 SQL 标签页，确认它使用的是正确的连接和上下文。先执行一条只读查询，例如：

```sql
SELECT *
FROM your_table
LIMIT 20;
```

将 `your_table` 替换为你能够访问的真实表名。执行后，在结果区域确认列和值是否符合预期。

## 5. 继续下一步

现在你已经完成了 NexusPilot 的基本闭环：连接 → 对象浏览 → 数据查看 → 查询执行。

- 想更系统地组织连接，请阅读[数据库连接](/docs/guides/managing-connections/)。
- 想理解连接树、标签页和状态如何协作，请阅读[工作台概念](/docs/getting-started/workbench-concepts/)。
- 遇到连接失败或结果异常时，请查看[故障排查](/docs/help/troubleshooting/)。
